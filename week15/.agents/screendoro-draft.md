# 초안 기록

## 사진 용량 줄이기 메인 화면 (2026-11-17)

### 초안 (사용자 원문)

> 일단 사진 줄이는 서비스니까 꼭 필요한 기능빼고는 아예 없었으면해
> 로그인 필요없이 사진 용량을 줄일수 있는 그런 서비스
>
> 사진용량은 기존에 얼마인지 보여주고, 이걸 얼마로 줄일지 사용자가 직접 적을수 있어야돼
> 그리고 사진의 확장자를 변경하고 싶을수도 있으니까 바꾸고자 하는 사진의 원래 확장자가 어떤건지 보여주고 이걸 어떤 사진 확장자로 바꿀건지 고를수 있는 기능도 있으면 좋겠어
> 사진 확장자를 바꾸는건 드롭박스 형태로 바꿀수 있도록 해줬으면 좋겠고, 사진용량을 바꾸는것의 경우는 사용자가 직접 타이핑 칠수있는 공간을 만들어줘
> 그리고 변환이 완료되면 따로 사용자가 저장 버튼을 누를 필요없이 변환완료 즉시 저장되도록 해주고
> 화질같은 경우 최대한 원본의 화질을 깨지 않는 방향으로 진행해줘

추가 답변 (질문 창에서 사용자가 고른 것. 선택지는 AI가 만들었다):

- 가장 중요한 것: 사진 올리는 영역
- 화면 순서: 사진을 올린 뒤에 나타남 (처음에는 사진 올리는 곳만, 올리면 용량·확장자 정보와 설정이 나타남)
- 레퍼런스: 없이 진행
- SPEC.md 항목 중 넣을 것: 사진 미리보기, 해상도 표시, 압축 전후 비교 (프리셋 버튼은 고르지 않음 → 넣지 않음)
- 저장 파일 이름: `_compressed` 붙이기
- 확장자 드롭박스: JPG, WebP, PNG
- 사진 수: 한 장씩
- 용량 단위: KB / MB 선택
- 빈칸: 올린 뒤 화면 안에서 요소들의 세부 순서, 변환이 끝난 뒤 화면의 구성

### AI 구조안

**처음 (사진을 올리기 전)**
1. 서비스 이름과 한 줄 설명
2. 사진 올리는 영역 — 화면에서 가장 크게. 끌어다 놓기와 눌러서 고르기
3. "사진은 기기 밖으로 나가지 않는다"는 안내 한 줄

**사진을 올린 뒤**
1. 올린 사진: 미리보기, 파일 이름, 기존 용량, 해상도, 원래 확장자, "다른 사진 고르기"
2. 목표 용량: 숫자 입력칸 + KB/MB 선택
3. 바꿀 확장자: 드롭박스(JPG / WebP / PNG), 처음 값은 원래 확장자
4. "줄이기" 버튼 — 누르면 진행 상태를 보여줌
5. 입력이 맞지 않을 때의 안내 (목표 용량이 기존 용량보다 큼 등)

**변환이 끝난 뒤**
1. "저장했다"는 알림과 저장된 파일 이름 (자동 저장)
2. 전후 비교: 기존 용량 → 줄인 용량과 줄어든 비율, 전후 사진 나란히, 해상도가 바뀌었으면 전후 해상도
3. 목표 용량을 못 맞췄을 때의 안내
4. "다시 저장" 버튼
5. "다른 사진 줄이기" 버튼
