전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 대표적인 세 가지 상황(하이픈 제거, 하이픈 추가, 특정 포맷으로 통일)에 맞춘 파이썬 함수들을 만들어 보았습니다.

### 1. 하이픈(`-`)을 모두 제거하여 숫자만 남기기
데이터 분석이나 DB 저장 시 가장 많이 사용되는 방식입니다.

```python
import re

def clean_phone_number(phone):
    # 숫자가 아닌 모든 문자를 제거합니다.
    return re.sub(r'\D', '', str(phone))

# 테스트
print(clean_phone_number("010-1234-5678"))  # 결과: "01012345678"
print(clean_phone_number("02.123.4567"))    # 결과: "021234567"
print(clean_phone_number("(010) 1234 5678")) # 결과: "01012345678"
```

### 2. 숫자만 있는 번호를 표준 하이픈 형식으로 만들기
`01012345678`을 `010-1234-5678`로 변환하는 함수입니다. 지역번호(02)와 휴대폰 번호(010)의 길이를 고려해야 합니다.

```python
def format_phone_number(phone):
    # 1. 일단 숫자만 추출
    nums = re.sub(r'\D', '', str(phone))
    
    length = len(nums)
    
    # 2. 길이에 따른 포맷팅
    if length == 11:  # 010-1234-5678 형식
        return f"{nums[:3]}-{nums[3:7]}-{nums[7:]}"
    elif length == 10:
        if nums.startswith('02'): # 서울 지역번호 (02-1234-5678)
            return f"{nums[:2]}-{nums[2:6]}-{nums[6:]}"
        else: # 기타 지역번호 (031-123-4567)
            return f"{nums[:3]}-{nums[3:6]}-{nums[6:]}"
    elif length == 9: # 아주 짧은 번호 예외 처리
        return f"{nums[:3]}-{nums[3:]}"
    else:
        return nums # 형식이 맞지 않으면 그대로 반환

# 테스트
print(format_phone_number("01012345678"))  # 결과: 010-1234-5678
print(format_phone_number("021234567"))   # 결과: 02-1234-567
print(format_phone_number("0311234567"))  # 결과: 031-123-4567
```

### 3. [종합판] 데이터 정제용 함수 (가장 추천)
실제 업무에서는 입력값이 제각각이기 때문에, **"먼저 숫자로 다 바꾼 뒤, 다시 예쁘게 포맷팅"**하는 방식이 가장 안전합니다.

```python
import re

def standardize_phone(phone):
    """
    입력된 전화번호를 숫자만 추출한 후, 
    표준적인 000-0000-0000 형식으로 변환합니다.
    """
    # 1. 숫자만 남기기
    digits = re.sub(r'\D', '', str(phone))
    
    # 2. 길이 확인 및 포맷 적용
    if len(digits) == 11:
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif len(digits) == 10:
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif len(digits) == 8: # 예: 1234-5678 같은 경우
        return f"{digits[:4]}-{digits[4:]}"
    else:
        return digits # 너무 짧거나 길면 원본(숫자만) 반환

# 다양한 입력 테스트
test_list = [
    "010-1234-5678",
    "02.123.4567",
    "(010) 9876 5432",
    "0311234567",
    "01011112222",
    "021112222"
]

for p in test_list:
    print(f"{p}  =>  {standardize_phone(p)}")
```

### 사용 팁:
1.  **Pandas와 함께 사용하기**: 만약 엑셀 파일이나 CSV 데이터를 정리 중이라면 다음과 같이 사용할 수 있습니다.
    ```python
    import pandas as pd
    df = pd.read_csv('data.csv')
    df['phone'] = df['phone'].apply(standardize_phone)
    ```
2.  **정규표현식(`re`)**: `re.sub(r'\D', '', ...)` 부분은 "숫자가 아닌 것(`\D`)을 찾아 빈 문자열(`''`)로 바꿔라"라는 뜻입니다. 이 코드가 전화번호 정제의 핵심입니다.
