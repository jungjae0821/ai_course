전화번호를 정리하는 함수는 **"어떤 형식으로 만들고 싶은가"**에 따라 달라집 수 있습니다. 가장 흔히 쓰이는 세 가지 패턴(숫자만 추출, 하이픈 추가, 특정 포맷 고정)을 기준으로 Python 코드를 작성해 드립니다.

### Python을 이용한 전화번호 정리 함수

```python
import re

def clean_phone_number(phone, mode='digits'):
    """
    전화번호를 정리하는 함수
    :param phone: 입력된 전화번호 (문자열)
    :param mode: 정리 방식 
                 'digits' - 숫자만 남김 (01012345678)
                 'hyphen' - 하이픈 추가 (010-1234-5678)
                 'pretty' - 괄호 포함 등 보기 좋게 (010 (1234) 5678)
    :return: 정리된 전화번호 문자열
    """
    # 1. 일단 모든 숫자가 아닌 문자를 제거하여 숫자만 추출합니다.
    digits = re.sub(r'\D', '', phone)
    
    if not digits:
        return ""

    # 2. 모드에 따른 처리
    if mode == 'digits':
        return digits

    elif mode == 'hyphen':
        # 길이에 따라 다른 패턴 적용 (휴대폰/일반전화/지역번호 대응)
        length = len(digits)
        if length == 11: # 010-1234-5678
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
        elif length == 10: # 02-123-4567 또는 010-123-4567
            if digits.startswith('02'): # 서울 지역번호
                return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
            else:
                return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        elif length == 9: # 02-12-3456
            return f"{digits[:2]}-{digits[2:4]}-{digits[4:]}"
        else:
            return digits # 형식이 맞지 않으면 숫자만 반환

    elif mode == 'pretty':
        # 예시: 010 (1234) 5678 형식
        length = len(digits)
        if length == 11:
            return f"{digits[:3]} ({digits[3:7]}) {digits[7:]}"
        return digits

    return digits

# --- 테스트 코드 ---
test_numbers = [
    "010-1234-5678",
    "01012345678",
    "02.123.4567",
    "010 1234 5678",
    "02-1234-5678",
    "abc-010-1234-abcd-5678"
]

print(f"{'원본':<20} | {'숫자만':<15} | {'하이픈':<15}")
print("-" * 55)
for num in test_numbers:
    digits = clean_phone_number(num, 'digits')
    hyphen = clean_phone_number(num, 'hyphen')
    print(f"{num:<20} | {digits:<15} | {hyphen:<15}")
```

### 코드 설명

1.  **`re.sub(r'\D', '', phone)`**: 정규표현식을 사용하여 숫자가 아닌 모든 문자(`\D`)를 빈 문자열로 바꿉니다. 이 과정을 거치면 `010-1234-5678`, `010.1234.5678`, `010 1234 5678` 모두 똑같이 `01012345678`이 됩니다.
2.  **모드별 분기**:
    *   **`digits`**: 데이터베이스 저장용으로 가장 좋습니다. 불필요한 기호를 모두 제거합니다.
    *   **`hyphen`**: 사용자에게 보여주는 용도로 적합합니다. 한국 전화번호 체계(02 시작, 010 시작, 9~11자리 길이)를 고려하여 슬라이싱(`[:]`)을 통해 하이픈을 넣습니다.
    *   **`pretty`**: 디자인 요소가 가미된 출력 방식입니다.
3.  **예외 처리**: 숫자가 아예 없는 경우 빈 문자열을 반환하도록 설계했습니다.

### 활용 팁
*   **데이터 전처리 시**: 엑셀이나 CSV 파일을 읽어와서 대량의 전화번호를 정리할 때는 `mode='digits'`를 사용하여 DB에 깔끔하게 저장하세요.
*   **UI 출력 시**: 웹사이트나 앱 화면에 보여줄 때는 `mode='hyphen'`을 사용하세요.
