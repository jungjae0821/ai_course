전화번호를 어떤 형식으로 정리하고 싶으신가요? 상황에 따라 가장 많이 쓰이는 세 가지 패턴(하이픈 추가, 숫자만 추출, 특정 형식 통일)을 파이썬 코드로 작성해 보았습니다.

### 1. 숫자만 남기고 하이픈(`-`)으로 정리하기
사용자가 `01012345678`, `010-1234-5678`, `010 1234 5678` 등 제각각으로 입력해도 **`010-1234-5678`** 형식으로 통일해주는 함수입니다.

```python
import re

def format_phone_number(phone):
    # 1. 숫자 이외의 모든 문자 제거
    digits = re.sub(r'\D', '', phone)
    
    # 2. 길이에 따라 하이픈 삽입
    if len(digits) == 11:  # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif len(digits) == 10: # 02-123-4567 또는 010-123-4567 형식
        # 앞자리가 02인 경우(서울)와 010인 경우를 구분하여 처리 가능하지만, 
        # 일반적으로는 뒤에서부터 4자리, 3자리로 끊는 것이 안전합니다.
        return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif len(digits) == 9:  # 02-1234-5678 (옛날 번호 등)
        return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}"
    else:
        return digits  # 형식이 맞지 않으면 숫자만 반환

# 테스트
test_numbers = ["01012345678", "010-1234-5678", "010 1234 5678", "021234567", "0101234567"]
for num in test_numbers:
    print(f"{num}  =>  {format_phone_number(num)}")
```

### 2. 데이터 정제용: 숫자만 추출하기 (DB 저장용)
데이터베이스에 저장할 때는 하이픈 없이 숫자만 저장하는 것이 나중에 검색하거나 관리하기 좋습니다.

```python
import re

def extract_only_digits(phone):
    # 숫자가 아닌 모든 문자를 빈 문자열('')로 대체
    return re.sub(r'\D', '', phone)

# 테스트
print(extract_only_digits("010-1234-5678")) # 출력: 01012345678
print(extract_only_digits("(02) 123-4567"))  # 출력: 021234567
```

### 3. 리스트 전체를 한꺼번에 정리하기
여러 개의 전화번호가 들어있는 리스트를 한 번에 깔끔하게 만들 때 유용합니다.

```python
def clean_phone_list(phone_list):
    def formatter(phone):
        digits = "".join(filter(str.isdigit, phone))
        if len(digits) == 11:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
        elif len(digits) == 10:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        return digits

    return [formatter(p) for p in phone_list]

# 테스트
raw_data = ["01012345678", "010-9876-5432", "02 111 2222", "010.5555.4444"]
print(clean_phone_list(raw_data))
# 결과: ['010-1234-5678', '010-9876-5432', '02-111-2222', '010-5555-4444']
```

### 💡 코드 설명 및 팁
1.  **`re.sub(r'\D', '', phone)`**: 정규표현식을 사용하여 숫자가 아닌 것(`\D`)을 모두 찾아 지워버리는 가장 강력한 방법입니다.
2.  **슬라이싱(`[:]`)**: 문자열의 특정 위치를 잘라내어 원하는 위치에 하이픈을 넣습니다.
3.  **예외 처리**: 전화번호가 너무 짧거나(예: 5자리) 너무 긴 경우를 대비해 조건문(`if len(digits) == ...`)을 사용했습니다.
