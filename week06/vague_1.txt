전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 흔히 쓰이는 **3가지 케이스(하이픈 제거, 하이픈 추가, 표준 형식 통일)**에 대한 파이썬 코드를 작성해 드립니다.

### 1. 기본 코드 (Python)

이 코드는 숫자만 남긴 뒤, 길이에 따라 자동으로 하이픈(`-`)을 넣어주는 기능을 포함합니다.

```python
import re

def format_phone_number(phone_str):
    # 1. 숫자 이외의 모든 문자 제거
    clean_number = re.sub(r'\D', '', str(phone_str))
    
    length = len(clean_number)
    
    # 2. 길이에 따른 포맷팅
    if length == 11:
        # 010-1234-5678 형식
        return f"{clean_number[:3]}-{clean_number[3:7]}-{clean_number[7:]}"
    
    elif length == 10:
        # 02-123-4567 또는 010-123-4567 형식
        if clean_number.startswith('02'): # 서울 지역번호
            return f"{clean_number[:2]}-{clean_number[2:5]}-{clean_number[5:]}"
        else: # 일반적인 10자리
            return f"{clean_number[:3]}-{clean_number[3:6]}-{clean_number[6:]}"
            
    elif length == 9:
        # 02-1234-5678 처럼 짧은 번호 대응 (필요시)
        return f"{clean_number[:2]}-{clean_number[2:6]}-{clean_number[6:]}"
        
    else:
        # 형식이 맞지 않으면 숫자만 반환하거나 에러 처리
        return clean_number

# --- 테스트 ---
test_numbers = [
    "01012345678",          # 붙어있는 경우
    "010-1234-5678",        # 이미 하이픈이 있는 경우
    "02.123.4567",          # 점으로 구분된 경우
    "(010) 1234 5678",      # 괄호와 공백이 있는 경우
    "021234567",            # 서울 지역번호 9자리
    "abc010-1234-5678def"   # 문자가 섞인 경우
]

print(f"{'원본':<20} | {'정리 후'}")
print("-" * 40)
for num in test_numbers:
    print(f"{num:<20} | {format_phone_number(num)}")
```

### 2. 기능별 상세 설명

#### ① 숫자만 추출하기 (`re.sub(r'\D', '', ...)`)
사용자가 `010-1234-5678`, `010.1234.5678`, `010 1234 5678` 등 어떤 방식으로 입력하더라도 상관없도록, 정규표현식을 사용하여 **숫자가 아닌 모든 문자(`\D`)를 빈 문자열로 치환**하여 제거합니다.

#### ② 조건부 포맷팅 (Length Check)
한국 전화번호는 길이에 따라 하이픈의 위치가 달라집니다.
*   **11자리:** `010-XXXX-XXXX` (휴대폰 대부분)
*   **10자리:** 
    *   `02-XXX-XXXX` (서울 지역번호 2자리인 경우)
    *   `031-XXX-XXXX` (경기 등 지역번호 3자리인 경우 - 위 코드는 10자리를 3-3-4로 처리하도록 되어 있으나, 필요시 로직 수정 가능)

### 3. 만약 Pandas(데이터 분석)를 사용 중이라면?

엑셀이나 CSV 데이터를 한꺼번에 정리해야 한다면 `apply` 함수를 쓰는 것이 훨씬 빠릅니다.

```python
import pandas as pd

# 샘플 데이터프레임 생성
df = pd.DataFrame({'raw_phone': ["01012345678", "021234567", "010-9876-5432", "0311234567"]})

# 위에서 만든 함수를 적용
df['clean_phone'] = df['raw_phone'].apply(format_phone_number)

print(df)
```

### 요약: 어떤 상황인가요?

2.  **예쁘게 하이픈을 넣고 싶다:** 위의 `format_phone_number` 함수를 그대로 복사해서 쓰시면 됩니다.
3.  **대량의 데이터를 처리해야 한다:** Pandas의 `.apply()` 방식을 추천합니다.
