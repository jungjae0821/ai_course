# 주차 요금 계산기 요구사항 (Parking Fee Calculator Spec)

## 1. 기술 스택

- 언어: Python
- GUI 라이브러리: Tkinter
- 데이터 저장 형식: JSON (프로그램 재시작 시 자동 로드)

## 2. 핵심 요구사항

### 2.1 시간 입력 및 유효성 검사

- 시각은 HH:mm (24시간제) 형식으로 입력한다.
- 출차 시간은 반드시 입차 시간보다 이후여야 한다.
- 잘못된 시간 형식(25:60, abc 등) 입력 시 사용자에게 경고 메시지를 출력하고 입력을 방지한다.
- 만약 입차와 출차 시간이 자정 기준 하루를 넘어가도 기존 시간로직 그대로 계산한다.
- 예를 들어 입차 시간이 24시간 형식 기준 23시인데 출차 시간이 24시간 형식 기준 10시라면 기존 로직 그대로 입차와 출차 시간대로 계산해서 주차요금 산정 (입차 시간이 출차시간보다 앞서야 한다는 메시지 출력안되게)

### 2.2 요금 계산 규칙

- **무료 구간**: 주차 시간이 30분 미만인 경우 요금은 **0원**이다.
- **유료 구간**: 30분 초과 시, 30분을 제외한 나머지 시간에 대하여 **10분 단위로 올림** 처리하여 계산한다. (예: 31분 주차 시 10분 1회 적용)
- **단위 요금**: 유료 구간에 대해 **10분당 500원**을 부과한다.
- **최대 요금**: 1회 주차(입차~출차) 시 발생하는 최대 요금은 **20,000원**을 초과할 수 없다.

### 2.3 기능 및 UI

- **목록 관리**: 계산 시마다 [입차 시간, 출차 시간, 주차 시간, 요금] 정보를 목록에 추가한다.
- **내역 수정**: 목록의 각 행에 수정 기능을 제공하며, 기존 내역을 입력창에 불러와 다시 계산한 뒤 해당 행을 갱신한다.
- **삭제 기능**: 목록의 각 행에는 삭제 버튼이 있으며, 삭제 시 전체 합계 금액이 즉시 재계산된다.
- **포맷팅**: 금액은 천 단위마다 쉼표(,)를 포함하여 표시한다.
- **입력 편의**: `2300`처럼 숫자 4자리로 입력하면 `23:00`으로 자동 변환하고, 입력 중 시·분 사이에 콜론을 자동으로 추가한다. 변환 후에도 잘못된 시간은 경고하고 저장하지 않는다.
- **데이터 영속성**: 프로그램 종료 시 데이터를 data.json에 저장하며, 프로그램 실행 시 자동으로 기존 내역을 불러온다.
- **내역 저장**: 현재까지의 모든 주차 내역을 텍스트 파일(.txt)로 내보내는 기능을 제공한다.

## 3. 상세 동작 규칙 (Business Rules)

| 구분 | 규칙 상세 | 비고 |
| :--- | :--- | :--- |
| **시간 형식** | `HH:mm` (24시간제) | 범위를 벗어난 시/분은 에러 처리 |
| **자정 처리** | `출차 < 입차` 일 경우, 출차 시간을 익일로 간주 | 예: 23:00 ~ 01:00 (120분) |
| **무료 적용** | 주차 시간 $\le$ 30분 $\rightarrow$ 0원 | 30분까지는 무료 |
| **유료 계산** | `(주차 시간 - 30분)`을 10분 단위로 올림 | $ceil((T - 30) / 10)$ |
| **요금 상한** | 단일 건 최대 20,000원 | 초과 금액은 청구되지 않음 |
