# 회의록 정리

## 작성 규칙

- 회의 메모에 나온 사실만 사용한다. 제안이나 검토 중인 내용을 확정된 결정으로 바꾸지 않는다.
- 회의 일시와 작성일을 구분한다. 메모에 없는 참석자, 담당자, 기한은 추측하지 않고 `미정`으로 쓴다.
- 상대 날짜는 회의 날짜를 기준으로 명확히 계산할 수 있을 때만 `YYYY-MM-DD`로 바꾼다. 모호하면 원문을 유지하고 확인 필요로 표시한다.
- 반복되는 의견은 합치되 결정 사항과 실행 과제는 빠뜨리지 않는다.
- 회의록 본문은 간결한 한국어 문어체로 작성한다.

## 출력 형식

파일명과 저장 위치는 요청을 따른다. 별도 지정이 없으면 현재 작업 폴더에 `meeting_minutes.md`로 저장한다. UTF-8 인코딩을 사용한다.

아래 순서로 작성한다.

1. `# 회의 제목`
2. `## 회의 정보`: 회의 날짜, 시간, 장소, 참석자. 제공되지 않은 항목은 `미정`.
3. `## 안건 및 논의`: 안건별로 논의 내용을 요약한다.
4. `## 결정 사항`: 확정된 내용만 목록으로 정리한다. 없으면 `확정된 결정 없음`.
5. `## 할 일`: `담당자 | 할 일 | 기한` 머리글의 마크다운 표. 담당자나 기한이 없으면 `미정`. 과제 자체가 없으면 표 대신 `등록된 할 일 없음`.
6. `## 미정 및 확인 사항`: 결정되지 않은 제안, 누락된 담당자·기한 등 후속 확인 내용을 쓴다. 없으면 `없음`.

## 저장 및 확인

Python 표준 라이브러리 `pathlib.Path.write_text(..., encoding="utf-8")`로 저장할 수 있다. 저장한 파일을 다시 읽고 결정 사항, 할 일의 담당자·기한이 원문과 일치하는지 확인한다. 완료 시 `saved 파일명`을 출력한다.
